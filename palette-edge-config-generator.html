Palette Connection
Leave as-is for Palette SaaS. Change for self-hosted instances.
Tenant Settings → Security → Registration Tokens → Add New
Edge Host
Password for the kairos local OS user.
Power off after install
Off = reboot automatically. On = shut down after flashing (ship-to-site workflow).
Provider Image Registry
⚠ ttl.sh can't host CanvOS provider images — its tag must be a TTL (1h–24h), not the semantic tag the cluster pulls. Use a persistent registry.
Alphanumeric lowercase only. e.g. poc-v1
Insecure registry (HTTP / no TLS)
Adds stylus.registryCredentials with insecure: true to user-data so the edge host pulls the provider image from an HTTP registry without TLS errors. Leave off for a TLS registry.
Kubernetes
Must match the cluster profile's k8s pack tag. See k8s_version.json for supported values.
Enable VMO (Virtual Machine Orchestrator)
Presets PXK-E + Ubuntu 22.04, loads kvm/vhost_net in user-data, and enables nested virt on the LXD test VM. KubeVirt 1.7 supports k8s 1.32–1.34 (not 1.35).
Piraeus host prep
Adds install.bind_mounts for /etc/lvm, /var/lib/drbd, /var/lib/linstor.d, /var/lib/piraeus so LINSTOR/DRBD state persists across reboots. Not needed for Longhorn.
Two-node HA mode
Replaces etcd with Postgres for HA with exactly 2 hosts. Image is not interchangeable with standard images.
⚠ Two-node image cannot be used for standard clusters.
Requires exactly 2 edge hosts in Palette. The custom tag is suffixed with -2node to distinguish this image.
Pipeline mode — placeholder secrets
Emit ${REGISTRATION_TOKEN} / ${OS_PASSWORD} in user-data instead of real values, so the build bundle carries no secrets (Jenkins injects them at build time). Turn off for manual / USB-stick builds.
